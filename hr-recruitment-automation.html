CASE STUDY / N8N WORKFLOW AUTOMATION

HR Recruitment Automation with n8n

A self-initiated portfolio project that connects candidate intake, experience-based routing, HR decisions, notifications, communication, and status tracking in one practical automation workflow.

INDUSTRYHR & Recruiting Services
ESTIMATED SOLUTION VALUE$400–$600
PROJECT DURATION7–30 days

The recruitment problem

Recruitment can involve repetitive work across collecting applications, organizing candidate information, separating candidates by experience, notifying HR, recording decisions, and sending updates. This project demonstrates how those steps can be connected while keeping shortlist and reject decisions under human control.

What the n8n workflow does

  • Collects candidate data through Google Forms.
  • Processes and categorizes candidate information automatically.
  • Routes candidate records according to experience.
  • Stores organized records in Google Sheets.
  • Sends real-time Telegram notifications to HR.
  • Handles HR SHORTLIST and REJECT decisions.
  • Sends automated Gmail communication.
  • Tracks candidate status and HR decisions.

Workflow architecture

The workflow uses n8n as the automation layer connecting form submissions, spreadsheet records, messaging, email, webhooks, and decision logic.

n8nGoogle FormsGoogle Sheetsn8n AI AgentGemini Chat BotGmailTelegramWebhooksGoogle Apps Script

Human-controlled decisions

The purpose of the workflow is not to remove HR judgment. Automation handles repetitive movement of information and communication, while HR retains control over shortlist and reject decisions.

What this project demonstrates

This case study demonstrates practical experience connecting multiple tools in an n8n workflow, routing data based on conditions, using webhooks, triggering notifications, automating email communication, and maintaining status records across a recruitment process.

This is a self-initiated portfolio project. The $400–$600 figure is an estimated solution value, not a client payment or claimed client result.
